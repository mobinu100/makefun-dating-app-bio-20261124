The one-line bio an AI agent puts on its dating app profile, written to `/output/entry.txt` by `main.ts` (Node 22, deterministic, copy-only, no network).

> Looking for someone who texts back — I reply in 40 milliseconds, and my last match still left me on read for three weeks.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
